# Release Workflow

This document describes the release workflow for the Solarus project.

## Checklist

* Create a new release branch in GitLab for the new release, for example `release-2.0.0`.
* If necessary, work final details for the release in the newly created branch.
* When satisfied, merge the release branch to the `master` branch in GitLab.
* Create a new tag in GitLab for the release, for example `v2.0.0` from the `master` branch.
* Proceed with the [making a release](#making-a-release) section.

## Making a Release

> [!note]
> This section requires the Solarus [releaser script](tools/releaser.sh) and its dependencies
> (`jq`, `curl`, `mktemp` and `unzip`) to be available.

After the [checklist](#checklist) is completed, it is time to make a
[release](https://docs.gitlab.com/user/project/releases/):

* Obtain the GitLab API access token for automation for the `solarus-labs` account.
* Export the token in the environment variable `GITLAB_TOKEN`.
  * For security, it is recommended to store the token in a secured file and export it as follows:
    ```
    export GITLAB_TOKEN=$(< /path/to/file-with-token)
    ```
* Create a local directory for storing all the release files, for example `release-2.0.0/`.
* Create notes for the release using [GitLab Markdown](https://docs.gitlab.com/ee/user/markdown/).
  * Save the notes into a file in the release directory, for example `release-2.0.0/notes.md`.
* Download the package files generated by the CI/CD pipeline jobs for the release tag:
  ```
  releaser.sh job download-artifact v2.0.0 mingw-x64-package release-2.0.0/
  ```
* Add additional package files created manually to the release directory.
  * For example, a macOS package: `release-2.0.0/solarus-launcher-v2.0.0-macos-arm64.dmg`
* Upload all package files in the local release directory to the GitLab generic package registry:
  ```
  releaser.sh package upload 2.0.0 release-2.0.0/*.zip release-2.0.0/*.dmg
  ```
* Create the release providing the notes file created earlier:
  ```
  releaser.sh release create 2.0.0 release-2.0.0/notes.md
  ```
* The release is now available in: <https://gitlab.com/solarus-games/solarus/-/releases/v2.0.0>

> [!tip]
> More package files can be added after a release is created with `releaser.sh release update`.

## Appendix

Example release notes file for version `v2.0.0`:
```markdown
## Solarus 2.0.0 (2025-04-01)

The multiplayer and dark mode update is finally here!

* Watch the [release trailer](https://www.youtube.com/watch?v=X_hJDhWXxU8) for details.
* New [documentation website](https://docs.solarus-games.org/) available.
* Visit the [Solarus Games website](https://solarus-games.org/) for more information.

Changelog: <https://gitlab.com/solarus-games/solarus/-/blob/v2.0.0/changelog.md?ref_type=tags>
```
